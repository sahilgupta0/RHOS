# RHOS AI Agents & Orchestration

Rural Health OS (RHOS) utilizes a hybrid multi-agent architecture powered by Google ADK (Agent Development Kit) and Gemini 2.5 Pro.

## Agent Architecture

We orchestrate 8 distinct, specialized agents using a `SequentialAgent` pipeline which updates a shared session state.

```
Root Agent (SequentialAgent)
├── Conversation Agent (LlmAgent) — Symptom extraction
├── History Agent (LlmAgent) — Past records compiler
├── Triage Agent (LlmAgent) — Urgency classifier (LOW/MEDIUM/HIGH)
├── Vision Agent (LlmAgent) — Objective medical image description (on-demand)
├── Medicine Agent (LlmAgent) — Drug interaction & allergy checker
├── Doctor Agent (LlmAgent) — Clinical note summarizer
└── Follow-up Agent (LlmAgent) — Care coordination & follow-up planner
```

## Detailed Agent Functions

1. **Conversation Agent**: Analyzes conversational transcripts (Hinglish/Hindi/English) and extracts structured lists of symptoms, durations, and severity levels.
2. **History Agent**: Scans past medical history and allergies, generating a quick-reference clinical abstract.
3. **Triage Agent**: Classifies patient priority into LOW, MEDIUM, or HIGH based on current vitals and symptoms. Follows conservative classification (biasing upward for safety).
4. **Vision Agent**: (Invoked on-demand) Describes visible anomalies (wound condition, skin lesions) objectively. *Explicitly constrained to NEVER diagnose.*
5. **Medicine Agent**: Validates drug safety against allergies, past conditions, and other scheduled medications. Proposes generic alternatives from NLEM (National List of Essential Medicines) lists.
6. **Doctor Agent**: Aggregates all session findings into a structured SOAP clinical note draft.
7. **Follow-up Agent**: Builds actionable follow-up plans, home monitoring advice, red flags, and ASHA community worker visits.

## Safety & Ethics Core Guidelines

- **Clinical Decision Support**: All AI agents are decision support aids. They are explicitly forbidden from making standalone diagnoses or prescriptions.
- **Verification Loop**: All plans, notes, and actions generated by AI agents must be explicitly reviewed and signed off by the clinician in the frontend before saving.
- **Conservative Triage**: In high-uncertainty scenarios, the Triage Agent is instructed to upgrade the triage priority to ensure patient safety.
